# Third Eye Vision — React + Tailwind Foundation

A premium Indian wedding photography website foundation inspired by the supplied reference image.

## Included

- React + Vite
- Tailwind CSS
- Framer Motion
- Lucide React icons
- Premium charcoal / ivory / muted-gold design tokens
- Playfair Display + Cormorant Garamond + Manrope typography
- Reusable Button component
- Reusable SectionHeading component
- Responsive Container component
- Responsive sticky Navbar with mobile drawer
- Cinematic Preloader with percentage/progress animation
- Motion utility presets
- Reduced-motion accessibility support

## Run

```bash
npm install
npm run dev
```

The current App intentionally contains only a foundation preview. The individual Hero, Highlights, Services, Offer Zone, Gallery, Testimonials and Footer sections can be added next.
